# Arabi9

کتێبی ئەلیکترۆنی عەرەبی پۆلی ٩

Arabi9 is a digital Arabic learning website for Grade 9 students.

## Features

* Arabic lessons
* Kurdish Sorani interface
* Kurdish translations
* Interactive quizzes
* Lesson questions and answers
* Dark Neon Glass design

## How to use

Open the website in a browser and choose a lesson to begin learning.
